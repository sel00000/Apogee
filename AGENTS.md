# Instructions for AI coding assistants

**Before every commit in this repository, read [`MERGE_NOTICE.md`](MERGE_NOTICE.md) in full and follow it.**

한결's home-page V3 is merged into `apps/portal`. Run `git pull` before editing `apps/portal/index.html`, `app.js`,
`home-story.js`, `home-background.js`, `home-src/*`, `routing.js` or `i18n/*`, and never overwrite them with a copy made
before the merge. If your change touches those files, tell the user what you changed before committing.

커밋 전에 반드시 `MERGE_NOTICE.md`를 읽으세요. 한결 홈 V3가 `apps/portal`에 병합되었습니다. 위 파일을 고치기 전에
`git pull`을 하고, 병합 이전 사본으로 덮어쓰지 마세요. 고쳤다면 커밋 전에 사용자에게 알리세요.

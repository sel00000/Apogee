    WELCOME TO THE SKY

    Stellarium Web Lab

    웹 브라우저에서 실행되는 나만의 천체 관측 도구입니다.

    ‘전천 지도’는 360° 하늘을 타원형 몰바이데 투영으로 펼칩니다. 별이나 별자리 이름을 클릭하면 정보를 표시합니다. 드래그·확대와 천체 검색을 사용할 수 있고, ‘전체 보기’로 지도를 초기화합니다. 하늘 보기로 돌아오면 이전 시야와 지표면·대기 설정이 복원됩니다.

    ‘스피어x 데이터 분석’을 누르면 커서에 분석 범위를 나타내는 네모가 표시됩니다. 네모를 원하는 곳에 놓고 클릭하면 해당 영역의 SPHEREx 자료를 조회합니다. 기본 범위는 3′ × 3′이며, 범위가 보이도록 필요한 만큼 확대됩니다. 네모는 천구의 북쪽을 기준으로 하므로 하늘의 방향에 따라 기울어 보일 수 있습니다. Esc 또는 버튼을 다시 누르면 취소하고, 분석을 열면 일반 선택으로 돌아갑니다.

    ‘좌표계’에서 천구 좌표계를 선택하거나 오른쪽 ‘천구’ 버튼을 누르면 적경·적위 격자로 볼 수 있습니다. 화면 중심 좌표를 확인하고, 적경(시간)·적위(도)를 입력해 이동하세요. 격자·표시·입력·분석 좌표는 광행차와 태양의 빛 휨을 보정한 ICRS 기준입니다.

    이 버전에 대하여

    공식 Stellarium Web Engine을 사용하는 웹 프로젝트입니다. 클릭한 하늘 위치를 보정한 ICRS 좌표로 변환해 SPHEREx 분석 화면으로 전달합니다. 자료 조회에는 인터넷 연결이 필요하며, 관측 범위와 품질에 따라 결과가 없을 수 있습니다. 이동 천체를 선택한 경우에는 선택 시각의 겉보기 방향을 구분하여 전달하며, 과거 경로를 자동 추적하지 않습니다.
